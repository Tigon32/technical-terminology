# Technical terminology

This repository stores shared engineering terms.
Each concept has a stable ID, a preferred term, and one definition.
Projects keep their domain terms in their own repositories.

The shared registry does not depend on Miniquad.
The project uses ASD-STE100 Issue 9 as a writing reference.
It does not copy the ASD-STE100 dictionary or claim full compliance.
